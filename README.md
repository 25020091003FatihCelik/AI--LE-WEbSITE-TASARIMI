# AI-ILE-WEBSITE-TASARIMI

AI-İLE WEBSITE TASARIMI

## Proje Açıklaması

Bu proje, Fatih Çelik tarafından geliştirilen bir web sitesi tasarımıdır. Geliştirme aşamasında modern ve kullanıcı dostu bir arayüz oluşturulmuştur. Web sitesi, yazılım mühendisliği hizmetleri sunan firmalara yöneliktir.

## Özellikler

- **Karanlık Mod**: Arka plan rengi siyah olup kullanıcı deneyimine uygun olarak tasarlanmıştır.
- **Neon Efektler**: Sayfa boyunca neon efektlerle görsel estetik artırılmıştır.
- **Animasyonlar**: Giriş ekranında yazı animasyonu, butonda yükleniyor animasyonu ve mouse hareketlerine tepki veren efektler eklenmiştir.
- **Responsive Tasarım**: Farklı ekran boyutlarına uyum sağlayan bir tasarım mevcuttur.
- **WhatsApp İkonu**: Sayfanın %70 aşağı kaydırıldığında WhatsApp ikonu görünür hale gelir.

## Kullanım

1. Projeyi klonlayın veya indirin.
2. `index.html` dosyasını bir web tarayıcısında açın.

## Geliştirme Ortamı

- **Cihaz Adı**: DESKTOP-OTCAASI
- **İşlemci**: AMD Ryzen 3 7320U with Radeon Graphics (2.40 GHz)
- **Takılı RAM**: 8,00 GB (kullanılabilir: 7.33 GB)
- **Grafik Kartı**: AMD Radeon(TM) 610M (486 MB)
- **Depolama**: 238 GB SSD SKHynix_HFS256GEJ4X112N
- **Sistem Türü**: 64 bit işletim sistemi, x64 tabanlı işlemci
